# Life Pilot 測試計畫與檢查點

本計畫依 2026 年 11 月 23 日程式版本 `f6948de9` 重新編寫。案例是待執行的驗收規格，不代表已在所有裝置通過。自動測試與人工驗收必須分開記錄；未執行不得標示通過。

## 1 測試目標

驗證 Life Pilot 在一般使用者、廠商與管理員角色下，能安全且一致地處理雲端與此裝置資料、分享、訂閱、特殊授權、投稿、圖片、分頁、外部快取及帳號生命週期。

本版優先風險：

- 帳號停用、恢復與正式刪除。
- 沒有適用方案時的全面唯讀。
- 本機核心不限量與雲端投稿／分享／圖片仍受限。
- 共享記帳與積分的唯讀、提案審核及圖片權限。
- 回憶與歷史明細跨過空白日期區間。
- SQL 彙總與畫面總計一致。
- 首屏早顯示、局部重試、查詢合併與舊回應隔離。
- 廠商投稿、工作台、互動成效與方案額度。

## 2 測試環境

至少準備：

- Android 手機與平板。
- iPhone 與 iPad。
- Chrome 或 Edge Web；有 Safari 發佈目標時另測 Safari。
- macOS 安裝包與 Windows 桌面版。
- 慢速網路、離線、逾時、403、404、500 與 RPC 不存在的隔離測試環境。

每次記錄 App 版本、Git 基準、平台、OS、裝置、語言、儲存模式、帳號角色、方案、資料庫 migration 版本與 Edge Function 版本。

## 3 測試帳號與資料

| 代號 | 用途 |
| --- | --- |
| ADMIN | 管理員，具帳號、方案、審核與特殊授權權限 |
| A | 一般雲端免費帳號 |
| P | 有效雲端付費帳號，可分享帳戶 |
| L | 有效本機方案或本機特殊授權帳號 |
| V | 廠商帳號 |
| B | 分享收件者 |
| D | 可停用、恢復及正式刪除的拋棄帳號 |

準備今天、昨天、跨月、跨年、過去一年、未來事件及中間有長日期空白的資料。為記帳與積分準備保留項、一般明細、多幣別及不同分類。圖片包含橫式、直式、超長圖、小圖、舊圖無縮圖與新高畫質縮圖。

## 4 優先級與通過規則

- P0：跨帳號洩漏、越權寫入、錯刪、轉移遺失、停用帳號仍可使用、方案繞過。
- P1：主要功能錯誤、總計不一致、分頁中斷、載入永久卡住、工作台錯誤。
- P2：不阻斷操作的版面、文案或次要視覺問題。

上線前所有 P0 必須完成且無未解缺陷；主要 P1 在目標平台至少一輪通過。每案保留實際結果、附件位置與缺陷編號。

## 27 自動化檢查

每次提交至少執行：

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

針對 migration 另檢查：

- App 呼叫的 RPC 名稱與參數存在。
- authenticated 與 anon 權限符合預期。
- `security definer` 固定 search_path 且驗證身分。
- 索引、trigger、快取失效與 schema reload 已包含。
- 退役 RPC 已盤點 App、Edge、靜態 SQL、資料庫函式及動態 SQL 依賴。

自動測試總數會隨版本變動。CI 顯示通過數不等於實機、通知、安裝、網路與權限案例已驗收。
