# Life Pilot 測試計畫與檢查點

## 測試目的與版本

本計畫依 2026 年 10 月 16 日工作樹及程式基準 41789f21 編寫，共 256 個獨立手動案例、28 組。案例是待執行的驗收規格，不代表已於實機通過；發現不符合預期時請留下缺陷，不要直接將預期當成既有事實。
自動測試基準為先前程式驗證的 832 項 Flutter 測試；不能替代本計畫的裝置、通知、網路與跨帳號驗收。此次文件產製不會執行破壞性測試。

## 測試環境與帳號

至少準備 Android 手機與平板、iPhone 與 iPad、Chrome 或 Edge Web；有 Safari 目標時另測 Safari。未持有的裝置標示未執行，不得以其他裝置通過代替。正式驗收用 release 或 profile；debug 可用於取 Log，但不能直接推論正式版速度。
Admin 為管理員測試帳號；A 為一般雲端帳號；B 為有額外模組授權的帳號；L 為有效本機訂閱帳號；V 為廠商；C 為對照或可拋棄帳號。各帳號不得使用真實客戶資料。額度案例不用 Admin，因 Admin 不限額度。
T 表示裝置當地今日。準備 T-100、T-30、T-29、昨日、今日、明日及跨月跨年資料。Q 表示當下該帳號、該儲存模式、該資源的有效額度，不把價格或筆數寫死。分別測 Q-1、Q、Q+1，及兩筆相同日期與不同日期訂閱。
照片準備無照片、小縮圖與數 MB 大圖；題庫準備零、一、二、三題與超過一頁資料。通知選測試開始後五至十分鐘，不等待一整天。只有可控制的隔離環境才測過期清理，不改正式時鐘或正式排程。

## 執行順序與安全

第一輪先測帳號隔離與資料安全，再測搬移與額度，接著主要功能，最後各遊戲、版面與效能。每組先記原始筆數與 ID，最後只刪測試新增資料。任何跨帳號可見、來源遺失、錯刪或越權寫入視為 P0，立即停止該路徑並保留現場。
P0 組為 SESS、SHARE、MOVE、SUB、EXP、CLEAN、LEGAL；其餘功能及效能預設 P1，純裝飾外觀 P2。每案至少記錄版本、裝置、OS、瀏覽器、語系、儲存模式、網路、操作時刻與實際結果。截圖不可包含密碼、JWT 或服務金鑰。
本機資料只屬目前裝置或瀏覽器；測試清除網站資料前先保護唯一副本。雲端轉本機驗證成功前不得手動刪來源。搬移不是跨雲端與裝置的單一資料庫交易，故障恢復需另驗。
